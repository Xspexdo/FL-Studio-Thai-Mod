โปรเจกต์นี้เปิดให้ **ดาวน์โหลดใช้งานฟรี 100% (ไม่มีระบบคีย์ ไม่ต้องต่อเน็ต)** ใช้งานแบบ **Offline** ได้สมบูรณ์แบบ ผ่านตัวติดตั้งสำเร็จรูปในหน้า [Releases](https://github.com/Xspexdo/FL-Studio-Thai-Mod/releases)!

## ✨ จุดเด่นและฟีเจอร์ (Features)
- 🇹🇭 **แปลภาษาไทยสมบูรณ์กว่า 2,326+ รายการ**: ครอบคลุมทุกส่วนสำคัญ ทั้งหน้าต่าง Playlist, Channel Rack, Piano Roll, Mixer, Browser, หน้าต่าง Welcome, และเมนูเครื่องมือทั้งหมด
- 🎮 **อินเทอร์เฟซแบบ Gaming HUD Overlay**: หน้าต่างดีไซน์สุดล้ำ ไร้กรอบ ปรับขนาดและลากได้อิสระ พร้อมหน้าต่าง Console Log แสดงสถานะแบบเรียลไทม์
- 🔄 **รองรับปุ่ม REVERT (กู้คืนภาษาอังกฤษเดิมได้ใน 1 คลิก)**: สามารถกดคืนค่ากลับเป็นภาษาอังกฤษโรงงาน (Factory English) ได้ตลอดเวลา พร้อมกู้คืนไฟล์ DLL และปลั๊กอินสำรองทั้งหมด
- 🔑 **คีย์เปิดใช้งานแบบ Public (xspexdo)**: ตัวติดตั้งใส่คีย์ `xspexdo` มาให้พร้อมใช้งานทันที หรือพิมพ์เองได้เลย
- 🔄 **รองรับหลายเวอร์ชันพร้อมกัน**: ตรวจจับและเลือกรุ่นติดตั้งได้ทั้ง FL Studio 2026, 2025, 2024 และ 21
- 🔌 **100% Offline Ready**: ฝังชุดข้อมูลภาษาไทยและสินทรัพย์ไว้ในตัว ไม่จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตก็ใช้งานได้สมบูรณ์แบบ

## 🚀 วิธีติดตั้งและใช้งาน (How to Install & Use)

### 🔹 ดาวน์โหลดและติดตั้งผ่านโปรแกรมติดตั้ง Gaming HUD (คลิกเดียวจบ)
1. ดาวน์โหลดไฟล์ `FL_Studio_Thai_Setup.exe` เวอร์ชันล่าสุดได้ที่หน้า 👉 [Releases (ดาวน์โหลดฟรีที่นี่)](https://github.com/Xspexdo/FL-Studio-Thai-Mod/releases)
2. เปิดไฟล์ `FL_Studio_Thai_Setup.exe` ขึ้นมา
3. ระบบจะใส่คีย์ `xspexdo` และตรวจจับเวอร์ชัน FL Studio ในเครื่องคุณให้อัตโนมัติ
4. กดปุ่ม **"INJECT THAI MOD (ติดตั้งม็อด)"** เพื่อติดตั้งภาษาไทย
5. *หากต้องการกลับเป็นภาษาอังกฤษเมื่อไหร่*: เพียงกดปุ่ม **"REVERT (กู้คืนภาษาเดิม)"** ได้ทันทีในคลิกเดียว!

## ⚙️ วิธีเปิดใช้งานภาษาไทยในโปรแกรม FL Studio
1. เปิดโปรแกรม **FL Studio**
2. ไปที่เมนูด้านบนซ้าย: **Options** ➡️ **General Settings**
3. ที่หัวข้อ **Language** ให้เลือกเป็น **Thai (ภาษาไทย)**
4. โปรแกรมจะแจ้งให้รีสตาร์ท ให้กด **Restart** 1 ครั้ง FL Studio จะกลายเป็นภาษาไทยสมบูรณ์ครับ
